# Harness sheet: Codex (how this runtime exposes the room)
- Tools: MCP tools are deferred behind tool search. At the start of every session search for `slp` and `paseo`; the room's `slp_*` tools and the Paseo tools your role allows are there. Do not conclude they are missing.
- Skills: your role's `slp-*` skills are in this runtime's skills directory; read one when a procedure names it.
- Off in this runtime: Codex native sub-agents, browser, computer use, apps. Do not look for them.
