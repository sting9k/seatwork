# Harness sheet: OpenCode (how this runtime exposes the room)
- Tools: the room's tools come from the `slp` and `paseo` MCP servers; names may carry a server prefix. The room's `slp_*` tools and the Paseo tools your role allows are there. Do not conclude they are missing.
- Skills: your role's `slp-*` skills are in this runtime's skills directory; read one when a procedure names it.
- Off in this runtime: OpenCode's own sub-agents (`task`, general, explore, scout). Do not look for them.
